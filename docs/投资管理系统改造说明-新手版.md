# 投资管理系统改造说明（新手版）

这份文档解释本次系统改造做了什么、为什么做、页面上的数字怎么算，以及目前哪些地方不能被误解成“预测收益”。

## 一、先说结论

这次改造的目标不是让系统保证赚钱，而是让它做到四件事：

1. 只显示当前用户自己的数据，避免不同账户串数据。
2. 把“赚了多少钱”和“承担了多大风险”分开看。
3. 把基金的官方分类、公开资产配置和披露持仓保存下来，和你的个人分类并列展示。
4. 根据已有净值和仓位，给出“买入观察 / 暂缓加仓 / 持有”等研究信号。

系统给出的都是辅助判断，不是自动交易指令，也不代表收益承诺。

## 二、数据安全和历史数据

### 1. 用户隔离

以前部分接口只按基金 ID 或投资方向 ID 查询。现在接口会先确认当前登录用户，再查询数据。

例如：

```text
用户 A 请求基金 27 → 只有当基金 27 属于用户 A 时才返回
用户 B 请求基金 27 → 返回“基金不存在”或无权访问
```

这不是删除数据，而是避免把别人的数据返回给当前用户。

### 2. 历史 AI 报告恢复

数据库里原有 8 条 AI 策略报告没有丢失，只是旧数据没有填写用户归属。确认后已将这 8 条报告归属到用户 ID 1，因此首页的历史策略分析已经恢复。

## 三、年度目标驾驶舱

首页现在会显示：

- 年度目标，例如 150,000 元；
- 当前已实现收益；
- 目标缺口；
- 距离年底剩余天数；
- 如果只靠当前市值，需要达到的数学收益率。

### 示例

假设：

```text
年度目标：150,000 元
今年已实现：17,445 元
目标缺口：132,555 元
当前市值：500,000 元
剩余 90 天
```

系统计算的“按当前市值所需收益率”大约是：

```text
目标缺口 ÷ 当前市值
= 132,555 ÷ 500,000
≈ 26.51%
```

这只是数学题，不是预测。它不能说明市场一定会涨 26.51%，也不能说明应该加杠杆或集中押注。

## 四、收益归因：钱是怎么赚或亏的

投资方向详情页现在会把收益拆成：

- 当前持仓收益：还持有的基金目前赚/亏多少；
- 已实现收益：已经卖掉的基金赚/亏多少；
- 现金分红；
- 红利再投资；
- 手续费；
- 组合总收益。

### 简化示例

```text
当前持仓收益：-8,000 元
卖出收益：+1,500 元
现金分红：+300 元
再投资分红：+100 元

组合累计收益
= -8,000 + 1,500 + 300 + 100
= -6,100 元
```

这样可以避免只看“当前持仓亏损”，却忽略之前卖出已经赚到的钱。

## 五、风险分析：不再只罗列收益

收益归因区域现在增加了以下指标。

### 1. 最大回撤

最大回撤表示：从历史高点跌到之后低点，最严重跌了多少。

```text
历史高点：100 元
之后最低：80 元
回撤 = (80 - 100) ÷ 100
= -20%
```

页面显示绝对值 20%，表示历史上曾经从高点回落约 20%。

系统会尽量扣除期间新增投入，避免把“后来加钱”误认为收益增长。

### 2. 年化波动率

波动率表示每天涨跌幅有多大。波动越高，净值曲线越不平稳。

系统先计算每天收益率的标准差，再按一年约 252 个交易日年化：

```text
年化波动率 ≈ 每日收益率标准差 × √252
```

波动率高不等于一定亏损，但表示持有过程可能更颠簸。

### 3. 夏普比率

夏普比率可以粗略理解为“承担一份波动，换来了多少收益”。

```text
夏普比率 ≈ 年化收益 ÷ 年化波动率
```

通常：

- 越高越好；
- 接近 0，说明收益不足以明显补偿波动；
- 为负，说明承担波动后仍然亏损。

数据太少时，系统不强行计算，会显示数据不足。

### 4. 回撤修复时间

如果净值从 100 跌到 80，后来又回到 100，用了 60 天，那么回撤修复时间就是 60 天。

如果目前还没有回到历史高点，系统不会假装已经修复。

### 5. 组合集中度 HHI

HHI 用来观察是否过度集中在少数基金上。计算方式是把每只基金权重平方后相加：

```text
基金 A：70%
基金 B：30%

HHI = 70² + 30²
     = 5,800
```

为了方便页面阅读，系统显示换算后的百分比形式。权重越集中，HHI 越高。

## 六、持仓结构饼图

收益归因区域的持仓结构已经改为环形饼图：

- 每一块代表一只当前有市值的基金；
- 面积代表该基金占投资方向当前市值的比例；
- 已清仓或 0% 的基金不会挤占图表空间；
- 鼠标悬停可以查看具体权重；
- 下方表格仍保留收益、分红、费用等明细。

### 示例

```text
黄金基金：37.7%
红利基金：13.4%
科技基金：10.1%
其他基金：38.8%
```

这能快速看出：某类资产是不是占比过高，而不仅仅是看单只基金赚了多少。

## 七、基金官方资料和个人分类

系统现在把两类概念分开：

### 个人分类

这是你自己设置的分类，例如：

```text
成长高风险、固收、黄金、红利
```

它适合做自己的投资计划和目标金额。

### 官方分类

这是从公开基金详情资料同步的分类，例如：

```text
指数型-海外股票
债券型-混合一级
混合型-偏股
QDII-普通股票
```

两者不会互相覆盖，页面会用“个人分类 / 官方分类”并列显示。

## 八、分类目标仓位怎么计算

现在只需要设置“目标仓位”，不再配置最低仓位和最高仓位。

目标仓位不是当前市值的比例，也不是历史平均值，而是这类资产计划使用的预期投入比例。

### 示例

假设一个投资方向的预期投入是 180,000 元：

```text
成长高风险：40% → 180,000 × 40% = 72,000 元
黄金：30%       → 180,000 × 30% = 54,000 元
红利：20%       → 180,000 × 20% = 36,000 元
固收：10%       → 180,000 × 10% = 18,000 元
```

四类目标仓位合计 100%，目标金额合计就是 180,000 元。

系统会用该分类的已投入金额和目标金额比较：

- 低于目标金额：说明还没有达到计划投入，可以继续观察是否需要买入；
- 达到目标金额：提示该分类已达到目标，不再建议继续加仓；
- 超过目标金额：标记为超出目标，但不会自动卖出。

当前市值仍然会展示，用来观察盈亏和当前组合结构，但不会改变目标金额。例如基金上涨后市值变成 80,000 元，不代表原本 72,000 元的目标金额自动变成 80,000 元。

目标仓位合计最好设置为 100%。系统只提供提醒和研究信号，不会自动买入、卖出或强制再平衡。

## 九、基金详情页的 metadataJson

基金详情页新增“基金官方资料”区域，系统会把数据库中的 `metadataJson` 解析展示为：

- 官方分类；
- 披露日期；
- 最近同步时间；
- 股票、债券、现金等资产配置；
- 前十大底层资产及披露占比；
- 数据来源和时效说明。

`metadataJson` 是一个资料快照，不是实时行情。例如：

```json
{
  "assetAllocation": {
    "股票占净比": 0,
    "债券占净比": 0.24,
    "现金占净比": 5.09
  },
  "holdings": [
    { "name": "25国债13", "weight": 0.24 }
  ]
}
```

部分基金没有公开完整持仓，页面会显示“暂无前十大持仓披露数据”，不能把缺失数据当成 0%。

## 十、P0 基金研究信号

首页的“今日基金信号”目前使用已有数据生成研究提示：

- 最近净值；
- 最近 20 个净值点的均线；
- 最近 5 个净值点的涨跌；
- 当前已投入金额占投资方向预期投入的比例；
- 当前基金市值权重（仅作组合结构参考）；
- 分类目标仓位（如果已设置）。

### 示例

```text
最新净值低于 20 日均线
最近 5 个数据点收益为负
当前仍有持仓
→ 观察 / 暂缓加仓
```

另一个例子：

```text
最新净值高于 20 日均线
最近 5 个数据点收益为正
当前已投入比例低于目标仓位
→ 分批买入观察
```

它不是“马上买入”或“马上卖出”，而是提醒你进一步检查基金资料、估值、市场环境和自己的现金流。

## 十一、AI 报告的限制

AI 报告现在被明确要求：对于系统没有的数据，必须写“数据不足”，不能编造，包括：

- 历史最高净值和真实最大回撤；
- 波动率、夏普比率、回撤修复时间；
- 基金具体业绩基准；
- 债券久期、信用评级和杠杆；
- 海外基金汇率贡献；
- 账户现金比例和全部家庭资产仓位；
- 预警价格的准确形成时间；
- 基金之间的相关性和组合压力测试。

这意味着 AI 报告里的“数据不足”是保护措施，不是系统故障。

## 十二、数据的时间和准确性边界

需要特别记住：

1. 基金净值通常是收盘后确认，不能等同于盘中实时价格。
2. QDII 基金受海外市场时差和汇率影响。
3. 基金底层持仓通常按季度或定期披露，不是实时持仓。
4. 公开资料接口可能暂时没有某些基金的类型或持仓。
5. 买卖信号只使用系统已保存的数据，不能替代交易平台最终确认。

## 十三、如何正确使用这个系统

建议每天按这个顺序看：

1. 先看年度目标缺口，不要因为缺口大就立即追高。
2. 看持仓饼图，确认有没有某只基金或某类资产过度集中。
3. 看最大回撤和波动率，判断自己能不能承受这类波动。
4. 查看基金官方分类和披露持仓，确认它是否真的符合你的计划。
5. 再看今日基金信号，把信号当作候选清单，不要当作自动指令。
6. 最后结合现金流、费用、确认日和自己的风险承受能力决定是否操作。

## 十四、当前没有做的事情

为了避免过度承诺，当前系统还没有：

- 自动买入或卖出；
- 盘中实时底层持仓；
- 保证收益的预测模型；
- 完整的基金相关性矩阵；
- 基于全家庭资产的压力测试；
- 自动判断某个信号一定正确。

这些功能如果以后增加，也应该先经过历史回测和风险校验，再考虑用于实际投资决策。
