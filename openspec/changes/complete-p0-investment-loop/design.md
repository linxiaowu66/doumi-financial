# 设计

1. `DataSyncRun` 保存用户级同步任务的种类、状态、日期、条数和错误信息；现有净值 cron 与且慢同步写入记录，页面显示最近状态。
2. `FundSignalExecution` 以用户、基金和信号日期为唯一执行记录，状态为待执行、已执行、部分执行或已跳过；执行金额由用户确认，不回写交易记录，避免把“建议”冒充“成交”。
3. 家庭再平衡使用当前家庭可识别市值、家庭政策目标比例和安全垫，计算每个大类的目标金额、缺口和建议增加 / 减少金额；其他类不参与自动分配。
4. 组合回测按统一目标权重在基金历史净值上执行：T-1 计算，下一可用净值成交，保留现金并扣除买卖费，返回收益、波动率、夏普、最大回撤、换手和交易次数。
