## Why

AI strategy reports render Markdown tables without the existing Markdown container styles, causing missing borders, cramped columns, and unreadable wrapping.

## What Changes

- Apply the existing Markdown report styles to the dashboard strategy report.
- Preserve intentional horizontal scrolling for wide tables on narrow screens.

## Capabilities

### New Capabilities

- None.

### Modified Capabilities

- `strategy-report-display`: Render AI strategy Markdown tables consistently on desktop and mobile.

## Impact

- Dashboard AI strategy report markup only.
