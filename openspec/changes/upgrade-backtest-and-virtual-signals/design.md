# 设计

1. 回测层保留 T-1 决策和下一可用净值点成交，新增 `INSUFFICIENT`、`RESEARCH`、`RECOMMENDED`、`ROBUST` 数据等级。
2. 组合回测将可用基金、被排除基金、观察日数量和覆盖区间一起返回；默认至少 126 个观察日，达到约三年数据后才允许盲测结论进入推荐状态。
3. 稳健性检查使用时间顺序切分：训练、验证、盲测；不随机打乱时间序列。费率压力测试和月度/季度再平衡敏感性使用同一历史区间。
4. `SignalVirtualAccount` 保存初始现金和账户状态，`SignalVirtualTrade` 保存信号日期、假设成交金额、价格、份额和费率；虚拟交易不会写入 `Transaction` 或 `FundSignalExecution`。
5. 虚拟账户只接受已有 BUY/SELL 信号或明确指定的历史回放结果，并使用基金净值作为假设成交价格；没有价格时拒绝记账。
